# dsh-session-ledger 0.1.0 发布说明

`dsh-session-ledger` 为 DeepSeek Harness 提供带来源的会话证据、用户确认式长期记忆和可审计生命周期。

## 已完成

- 复用 `ctx.sessionQuery` 检索和读取历史事件；
- 使用 `ctx.storageDomain` 持久化候选、记忆和审计记录；
- 工作区边界、敏感信息脱敏、来源内容哈希和证据变更校验；
- 通过 `ctx.userQuestions.ask()` 展示保存/拒绝选择；
- HMAC 确认令牌、幂等晋升、拒绝、撤销和删除；
- 真实 Domain 重启恢复测试和 Host 启动 smoke；
- 100,000 事件参考基准及可重复的 `npm run bench:m4`。

## 安装与验证

```bash
export DSH_SESSION_LEDGER_SECRET="use-a-profile-specific-random-secret"
dsh plugin --profile demo add /absolute/path/to/dsh-session-ledger
dsh --profile demo --dump-config
npm test
npm run bench:m4
```

宿主 profile 需要提供 `sessionQuery`、`storageDomain` 和 `userQuestions`。插件将 `SessionHeader.cwd` 作为第一版 workspace key。

## 当前限制

- 参考基准不是官方 SQLite provider 的性能承诺；
- 本机参考重启加载为 1.37 秒，尚未达到 1 秒目标；
- 尚未绑定具体 UI 组件，依赖 Harness answerer 渲染 approval intent；
- 不做向量召回、自动晋升、云同步或无条件 prompt 注入；
- workspace registry ID 适配仍待上游稳定接口。
